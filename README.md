# Java Combat Game

A turn-based combat game built in Java.

Choose between four different character classes — Fighter, Rogue, Wizard, or Cleric and fight your way through enemies and bosses across multiple levels.

Each character has different abilities. As you progress, battles become more challenging and require different strategies to win.

## Features

- Four playable character classes
- Turn-based combat
- Multiple levels
- Boss battles
- Character-specific abilities
- Level progression
